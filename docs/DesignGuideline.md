## 1. 一言で

**「やわらかい台紙の上に、色の濃いブロックが置いてある」**

背景は淡いグレーがかった白で、ほぼ無地。その上に角を大きく丸めた彩度の高いカード（紫・コーラル・黄・緑）が浮いている。カード以外の要素は白かグレーに寄せ、色はカードと主要ボタンだけに使う。全体に余白が多く、文字は太めの丸ゴシック系で親しみやすい。

リファレンス画像が持つ性質を分解すると：

| 要素 | 観察 | Yomi での扱い |
|---|---|---|
| 背景 | `#F3F4F8` 付近の青みグレー白。カードとの間にごく薄い影 | そのまま採用 |
| カード色 | 紫 / コーラル / 黄 / 緑の 4 色。塗りベタで白文字 | **ソース種別**に割り当てる（§3） |
| 角丸 | カード 24–28pt、ボタン・チップは完全な pill | 採用 |
| 切り欠き | カード右辺の丸い「ノッチ」 | **シグネチャ要素**として Today's Pick カードにのみ使う（§6） |
| タブバー | 画面下に浮いた紫の pill 型バー。アイコンのみ、選択中は白ドット | 採用 |
| 挨拶ヘッダー | "Good morning, Anna Lane!" の 2 行。小さいグレー + 大きい黒 | 「おはよう」ではなく **未読件数を主語**にする（§7） |
| 検索バー | 白、pill、左に虫眼鏡、右に紫のフィルタボタン | Library にそのまま |
| アイコン | 角丸の正方形の上に単色ピクト、半透明の白地 | ソースアイコンの器として採用 |
| 書体 | ジオメトリック系サンセリフ、太め、字間やや広め | §4 |
| 密度 | 1 画面に要素が少ない。スクロール前提 | 採用。詰め込まない |

## 2. カラートークン

### 2.1 ベース

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#F3F4F8` | 画面背景 |
| `surface` | `#FFFFFF` | 白カード、検索バー、リスト行 |
| `surface-muted` | `#EEF0F5` | 入力欄、非活性チップ |
| `ink` | `#1B1D2A` | 見出し・本文 |
| `ink-2` | `#6B7080` | 補足、日付、プレースホルダ |
| `ink-3` | `#A9ADB9` | 区切り、非活性アイコン |
| `line` | `#E4E6EE` | 罫線（使用は最小限） |

### 2.2 ブランド

| トークン | 値 | 用途 |
|---|---|---|
| `brand` | `#6C5CE7` | タブバー、主ボタン、選択状態、Pro 表記 |
| `brand-soft` | `#ECEAFD` | brand の淡色背景（バナー、選択チップ） |

### 2.3 ソースカラー（4 色）

リファレンスの 4 色を**保存元の種別**に割り当てる。ユーザーは「色＝どこから来たか」を学習する。

| トークン | 値 | 割り当て |
|---|---|---|
| `src-violet` | `#6C5CE7` | X / Threads（SNS テキスト系） |
| `src-coral` | `#F16B62` | Instagram / YouTube（ビジュアル・動画系） |
| `src-amber` | `#F5B942` | Zenn / Qiita / note / Medium（技術記事・ブログ系） |
| `src-green` | `#4FB871` | 一般 Web |

- カード塗りは上記そのまま、文字・アイコンは白
- リスト行ではカード塗りは使わず、**左端のソースアイコン（32×32、角丸 10）の背景色**にだけ使う
- ブランド紫と X の紫は同色。タブバーと X カードが同時に見えても違和感が出ないよう、X カードには必ず「𝕏」アイコンを載せる

### 2.4 ステータス

| トークン | 値 | 用途 |
|---|---|---|
| `warn` | `#F5B942`（= src-amber） | 7 日超放置バッジ |
| `danger` | `#F16B62`（= src-coral） | 30 日超放置バッジ、削除 |
| `ok` | `#4FB871`（= src-green） | 読了チェック、保存成功トースト |

ソースカラーと共有することで色数を増やさない。バッジは**小さい pill に白文字**で、カードと混同しないサイズにする（高さ 20pt）。

### 2.5 ダークモード

| トークン | Light | Dark |
|---|---|---|
| `bg` | `#F3F4F8` | `#121420` |
| `surface` | `#FFFFFF` | `#1C1F2E` |
| `surface-muted` | `#EEF0F5` | `#262A3B` |
| `ink` | `#1B1D2A` | `#F2F3F7` |
| `ink-2` | `#6B7080` | `#9DA2B3` |

ブランド・ソース・ステータス色はダークでも変えない（彩度が高いので暗背景でも成立する）。

## 3. 形状

| 要素 | 角丸 | 備考 |
|---|---|---|
| 大カード（Today's Pick、Stats の数値カード） | 28 | |
| 中カード（リスト行、白カード） | 20 | |
| 小要素（ソースアイコン器、サムネ） | 10–12 | |
| ボタン・チップ・検索バー・タブバー | 999（pill） | |
| bottom sheet 上辺 | 28 | |

影：`shadow-color: #1B1D2A, opacity: 0.06, radius: 16, offset: (0, 6)`。白カードにのみ付ける。色カードには付けない（浮きすぎる）。

## 4. タイポグラフィ

| ロール | フォント | サイズ / ウェイト | 用途 |
|---|---|---|---|
| Display | **Outfit** Bold | 28 / 700, letter-spacing −0.3 | ヘッダーの大見出し |
| Heading | Outfit SemiBold | 20 / 600 | セクション見出し、カード内タイトル |
| Body | Outfit Medium | 15 / 500 | リスト行タイトル（最大 2 行） |
| Caption | Outfit Regular | 13 / 400 | 日付、ソース名、補足 |
| 日本語 | **Zen Kaku Gothic New** | 同上の対応ウェイト | 英数は Outfit、和文は Zen Kaku にフォールバック |

- 両方 Google Fonts。`expo-font` でバンドル
- 数字（Stats、件数）は Outfit のまま。Zen Kaku に混ぜない
- 行間：タイトル 1.3、本文 1.5

## 5. レイアウト

- 画面左右マージン **20pt**。カード間 **12pt**。セクション間 **28pt**
- リスト行高 **76pt**（サムネ 56、上下 10）
- タブバー：幅は画面幅 − 40、高さ 64、下から 24pt 浮かせる。背景 `brand`。アイコン 4 つ、選択中は下に 4pt の白ドット。ラベルなし
- タブバーの下にコンテンツが隠れるので、各リストの `contentInset.bottom = 100`
- ヘッダーはナビバーを使わず、コンテンツ先頭に直接 Display テキストを置く（リファレンス通り）

## 6. シグネチャ：ノッチ付き Today's Pick カード

リファレンスで最も特徴的なのは**カード右辺の丸い切り欠き**。これを Yomi 内で**唯一** Today's Pick に使う。

```
┌──────────────────────────────╮
│ TODAY'S PICK            ⟳    │
│                              ╰──╮  ← 半径 18 の円で切り欠き
│ [サムネ]  Rails 8 の          │  │     内側に「開く →」の丸ボタン（白）
│           Solid Queue 入門    ╭──╯
│           zenn.dev · 12日前   │
╰──────────────────────────────╯
```

- 塗りはそのアイテムの**ソースカラー**。毎日色が変わる
- 切り欠きの内側に白い丸ボタン（44×44、矢印アイコン）。ここをタップで Browser
- 実装：`react-native-svg` で Path マスク、または `expo-skia`。スキアはまわコレで使用実績あり
- 他のカードに切り欠きは使わない。1 画面に 1 つだけ

## 7. コピーのトーン

- ヘッダーは挨拶ではなく状態：「未読 23 件」をDisplay、上に Caption で「今日も 1 本」
- 空状態は次の行動：「未読はありません。X で見つけたら共有してください」
- ボタンは動詞：「保存」「開く」「読んだ」「あとで」「アーカイブ」。「OK」「送信」は使わない
- 数字は煽らない。「▼15pt」は出すが、感嘆符や絵文字は付けない
- Pro の誘導は「残り 5 件」のように事実だけ。「今すぐアップグレード！」は書かない

## 9. やらないこと

- グラデーション、ガラス風の透過
- 1 画面に色カードを 5 枚以上並べる
- 色カードに影を付ける
- ノッチを Today's Pick 以外に使う
- 和文にウェイト 700 超を使う（潰れる）
- アイコンに複数色を使う（常に単色）
- ストリーク炎、紙吹雪、バッジ獲得演出

## 10. 実装メモ（NativeWind）

```ts
// tailwind.config.ts
export default {
  theme: {
    extend: {
      colors: {
        bg: '#F3F4F8', surface: '#FFFFFF', 'surface-muted': '#EEF0F5',
        ink: '#1B1D2A', 'ink-2': '#6B7080', 'ink-3': '#A9ADB9', line: '#E4E6EE',
        brand: '#6C5CE7', 'brand-soft': '#ECEAFD',
        'src-violet': '#6C5CE7', 'src-coral': '#F16B62', 'src-amber': '#F5B942', 'src-green': '#4FB871',
      },
      borderRadius: { card: '20px', 'card-lg': '28px', icon: '10px' },
      fontFamily: { display: ['Outfit_700Bold'], heading: ['Outfit_600SemiBold'], body: ['Outfit_500Medium'], caption: ['Outfit_400Regular'] },
    },
  },
};
```

`src/ui/tokens.ts` に同じ値を export し、SVG / Skia 側からも参照できるようにする。色をコンポーネント内にハードコードしない。
