## 1. 全体構成

```
Onboarding (初回のみ)
  └─▶ Tabs
        ├─ Home      (未読キュー)
        ├─ Library   (既読・アーカイブ)
        ├─ Stats     (週次サマリ)
        └─ Settings

モーダル / プッシュ遷移
  ├─ Item Detail        (各タブの行タップ)
  ├─ Browser            (SFSafariViewController)
  ├─ Read Confirm Sheet (Browser を閉じた直後)
  ├─ Memo Sheet         (Read Confirm で「読んだ」)
  ├─ Tag Picker Sheet
  ├─ Stale Items        (Home の放置バナー / Settings から)
  ├─ Paywall
  └─ Dev Unlock         (Settings のバージョン 7 タップ)

Share Extension（別プロセス）
  └─ Save Card
```

expo-router のファイル構成：

```

├── onboarding/
│   ├── _layout.tsx
│   ├── index.tsx          # 1. コンセプト

│   └── notify.tsx         # 3. 通知時刻 + 権限
├── (tabs)/
│   ├── _layout.tsx
│   ├── index.tsx          # Home
│   ├── library.tsx
│   ├── stats.tsx
│   └── settings/

├── paywall.tsx            # presentation: modal
└── dev-unlock.tsx         # presentation: modal
```

## 2. 画面一覧

| ID | 画面 | 種別 | 主目的 |
|---|---|---|---|

| X01 | Share Extension Save Card | Extension | 保存 |

### S04 Browser + S05 Read Confirm

SFSafariViewController。閉じた直後（`onDismiss`）に S05 を表示。Settings「読了確認」が OFF の場合は S05 を出さず Home に戻る（既読化はスワイプで行う）。

```
S05                                S06
┌─────────────────────────────────┐ ┌─────────────────────────────────┐
│                                 │ │                                 │
│     読み終えましたか？            │ │  ひとこと残す（任意）             │
│                                 │ │  ┌─────────────────────────────┐│
│   [   読んだ   ]  [ まだ ]       │ │  │ 何を得た？                   ││
│                                 │ │  └─────────────────────────────┘│
└─────────────────────────────────┘ │        [保存]   [スキップ]        │
                                    └─────────────────────────────────┘
```

- 「読んだ」→ `read` + `read_logs` 追加 → S06
- 「まだ」→ 何もしない。ただし同じアイテムで 3 回「まだ」なら「あとでにしますか？」を提案
- 滞在 10 秒未満で閉じた場合は S05 を出さない（誤タップ対策）

### X01 Share Extension Save Card

共有シート上に出る小さなカード。2 秒以内に閉じる。

```
saving          saved                     duplicate           limit
┌──────────┐    ┌────────────────────┐    ┌──────────────┐    ┌──────────────────┐
│ ◌ 保存中  │ →  │ ✓ 保存しました       │    │ ⓘ 保存済みです  │    │ 保存上限（50件）   │
└──────────┘    │ [rails] [db] [+]    │    │ [閉じる]      │    │ アプリで Pro に    │
                │ (タグは任意・1つ)    │    └──────────────┘    │ アップグレード     │
                └────────────────────┘                        │ [閉じる]          │
                   ↑ 0.6 秒後に自動 close                     └──────────────────┘
                     タグタップで close を延長
```

- タグチップは直近使用 5 件を `tags` から読む。タップで `item_tags` に INSERT して close
- 「+」で新規タグ入力は Extension では**しない**（本体で行う）

## 4. 主要フロー

```
保存:   X → 共有 → X01(saved) → 自動 close
消化:   通知タップ → S04 Browser → 閉じる → S05(読んだ) → S06(メモ) → Library へ移動
        Home Today's Pick → S04 → … 同上
整理:   Home バナー → S10 → 複数選択 → アーカイブ
課金:   X01(limit) → 本体起動 → Home 上部バナー → S12 → 購入 → isPro キャッシュ更新
```

## 5. デザイン方針

DesignGuideline.md を参照。色カード＋丸ゴシック＋浮いた紫タブバーのテイスト。放置バッジ（黄 / 赤）はソースカラーと共有する。

## 6. 決定事項

| 項目 | 決定 | 補足 |
|---|---|---|
| Today's Pick | 未読からランダム 1 件 | 日付をシードに選び、同日中は固定。⟳ で引き直し可。スヌーズ中は除外 |
| 読了確認シート（S05） | 毎回出す。Settings で OFF 可 | OFF 時はスワイプで既読化 |
| Library | 既読 / アーカイブのセグメント | アーカイブはゴミ箱相当。既読メモの振り返りを主用途とする |
