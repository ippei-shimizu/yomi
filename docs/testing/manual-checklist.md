# 実機での手動確認チェックリスト

Share Extension・課金・通知は自動テストできないため（`docs/DesignDoc.md` §8）、
dev build のたびにここを確認する。

開発は Linux コンテナ上で行っており、**iOS ビルド・Share Extension・課金・通知・E2E は
一度も実行できていない**。最初の dev build では「初回のみ」の項目を優先する。

## 初回のみ（最優先）

これらが通らないと、その先の確認に進めない。

- [ ] `npx expo prebuild --platform ios` が成功する
- [ ] `pod install` が成功する
- [ ] **Xcode でのコンパイルが通る**
      `expo-share-extension` は公式には SDK 54 までの対応。SDK 57 での
      コンパイルは未検証（#35）。**落ちた場合は SDK 54 へのダウングレードを検討する**
- [ ] アプリが起動し、マイグレーションが適用される
- [ ] `CREATE VIRTUAL TABLE items_fts USING fts5(... tokenize='trigram')` が通る（#50）
      通らないとマイグレーションが失敗し、アプリが起動しない
- [ ] `Paths.appleSharedContainers['group.jp.ippei.yomi']` がコンテナを返す（#36）

## Share Extension（#41）

- [ ] Safari の共有シートに Yomi が表示される
- [ ] X アプリの共有シートに Yomi が表示される
- [ ] **保存から自動で閉じるまで 2 秒以内**（US-1 の受け入れ条件）
- [ ] タイトルもタグも入力せずに保存できる（US-2）
- [ ] 保存したものが本体アプリの Home に出る
- [ ] 同じ URL を再度共有すると「保存済みです」が出る
- [ ] タグチップ（直近使用 5 件）が出て、タップで付けられる
- [ ] タグをタップすると自動クローズが延びる
- [ ] 無料プランで 50 件に達すると「保存上限」が出る
- [ ] Extension のバンドルに RevenueCat / PostHog / Sentry が含まれない

## メタデータ取得（#39 / #40）

- [ ] Zenn / Qiita / note の OGP が取得できる
- [ ] X の oEmbed が取得できる（**rate limit も観察する**。`docs/DesignDoc.md` §10 の未決事項）
- [ ] YouTube のサムネイルが取得できる
- [ ] Instagram / Threads は `@username` がタイトルになる（fetch しない）
- [ ] **短縮 URL（`t.co`）が HEAD で展開され、`url` が更新される**
      `redirect: 'follow'` 後の `response.url` が展開先になるかに依存（#40）
- [ ] 取得失敗が 3 回でリトライを止める
- [ ] バックグラウンドでの取得が動く（OS 裁量。数時間観察する）

## 読了フロー（#43）

- [ ] Home の行タップで SFSafariViewController が開く
- [ ] **ブラウザを閉じると `openBrowserAsync` の await が解決する**（滞在時間の計測がこれに依存）
- [ ] 10 秒以上滞在して閉じると読了確認が出る
- [ ] 10 秒未満で閉じると出ない
- [ ] 「読んだ」→ メモシート → 保存 / スキップ
- [ ] 「まだ」を 3 回選ぶと「あとでにしますか？」が出る
- [ ] Settings で読了確認を OFF にすると出ない

## 通知（#44）

- [ ] Onboarding 3/3 で権限ダイアログが出る。拒否しても先に進める
- [ ] 通知が指定時刻に発火する
- [ ] **通知に出たアイテムと、その日の Today's Pick が一致する**
- [ ] 通知タップでブラウザが直接開く
- [ ] アプリ終了状態からの通知タップでも遷移する
- [ ] 未読 0 件のときは通知が来ない

## 課金（#46 / #48）

RevenueCat Sandbox + StoreKit Configuration file を使う（`docs/DesignDoc.md` §8）。

- [ ] 月額 / 年額 / 買い切りの 3 プランが表示され、価格がローカライズされる
- [ ] 年額に「7日間無料」バッジが出て、既定で選択されている
- [ ] 3 プランすべて購入できる
- [ ] **購入直後に Share Extension 側の上限判定が解除される**（App Group 経由の伝播）
- [ ] 購入をキャンセルしてもエラーが出ない
- [ ] 「購入を復元」が動く
- [ ] **審査要件**: 価格・期間・自動更新の明記、規約 / ポリシーのリンク、復元ボタン
- [ ] 買い切り後にサブスクが残っているケースの表示（`docs/DesignDoc.md` §10 の未決事項）

## Dev Unlock（#48）

- [ ] 鍵ペアを生成し、公開鍵を `devOverride.ts` に埋め込む（未設定のあいだは動かない）
- [ ] Settings のバージョン 7 回タップで開く。誤爆しない
- [ ] 正しいコードで Pro になる
- [ ] 改竄 / 期限切れのコードが拒否される
- [ ] アプリ再起動後も維持される（Keychain）
- [ ] 「解除」で無料プランに戻る

## 見た目（#38 / #42 ほか）

自動テストで一切カバーできていない領域。

- [ ] **Today's Pick の切り欠きが意図どおり描かれる**。白い丸ボタンが収まる
- [ ] 浮いたタブバー（幅 = 画面幅 − 40、下から 24pt）
- [ ] リストの最後の行がタブバーに隠れない
- [ ] ダークモードで各画面が破綻しない
- [ ] Outfit / Zen Kaku Gothic New が適用される。和文と英数の混在
- [ ] スワイプの閾値（幅の 40%）が操作感として妥当。縦スクロールと競合しない
- [ ] Stats の棒グラフが 8 週分収まる
- [ ] 小さい端末（iPhone SE）で数値カード 3 枚が崩れない

## プライバシー（#53）

- [ ] **PostHog のダッシュボードに URL・タイトル・メモが出ていない**
- [ ] **Sentry のイベントに URL が出ていない**（意図的に例外を起こして確認）
- [ ] プライバシーポリシーの記載と実際の送信内容が一致している

## 法務ページ（#30）

- [ ] **`src/features/legal/operator.ts` の事業者情報を実際の値で埋める**。空のままだと
      特定商取引法に基づく表記に「（提出前に記入）」が出たまま提出することになる（**提出ブロッカー**）
- [ ] 設定 → 情報 から 3 つの文書すべてに到達できる
- [ ] 購入画面から利用規約とプライバシーポリシーに到達し、**戻ると購入画面に戻る**
- [ ] 長文がダークモードで読める。行間と余白が破綻しない
- [ ] 表記の価格が購入画面の価格と一致している（RevenueCat の実売価格を含めて確認）
- [ ] `docs/` 側にも同じ文面を掲載する必要があるか確認する（App Store Connect は
      プライバシーポリシーの **URL** を要求するため、Web 上にも同じ内容が必要）
